Plataforma de Estudos por Flashcards (Repetição Espaçada)

Implemente uma ferramenta de memorização baseada em baralhos de cartões de frente e verso. A interface deve utilizar animações CSS para virar o cartão ao clique do usuário, revelando a resposta e apresentando três botões de autoavaliação: "Difícil", "Bom" e "Fácil". O login OAuth2 do Discord identifica o estudante e carrega seus baralhos pessoais. O banco de dados Cloudflare D1 armazena os cartões e a data da próxima revisão de cada item. Quando o usuário avalia um cartão, uma Cloudflare Function aplica um algoritmo simplificado de repetição espaçada (inspirado no SuperMemo SM-2), recalculando o intervalo em dias para a próxima aparição daquele cartão e atualizando a fila de estudos diária do aluno.
