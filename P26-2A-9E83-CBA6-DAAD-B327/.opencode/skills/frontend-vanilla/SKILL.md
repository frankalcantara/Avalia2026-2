# Frontend Vanilla
1. Usar HTML semântico, CSS responsivo, JS com DOM e fetch.
2. Manter URLs de API relativas e mensagens de erro úteis.
3. Nunca colocar segredo no frontend; escapar dados no DOM e usar rel=noopener para links externos.
4. Conferir navegação por teclado e estados de carregamento.
