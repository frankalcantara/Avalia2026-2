Clone do Termo (Wordle) Diário

Construa um jogo de adivinhação de palavras de cinco letras com limite de seis tentativas diárias. A interface deve utilizar manipulação direta do DOM para renderizar o teclado virtual e a grade de letras, aplicando animações CSS para indicar letras corretas, presentes na posição errada ou ausentes. O login obrigatório via Discord OAuth2 identificará o jogador antes de liberar o tabuleiro do dia. O sorteio da palavra diária e a validação de cada tentativa devem ser processados por uma API serverless na Cloudflare, garantindo que a resposta correta nunca fique exposta no código-fonte do navegador. O banco de dados D1 deve armazenar as tentativas realizadas no dia atual para bloquear trapaças via recarregamento de página, além de consolidar estatísticas históricas como sequência de vitórias (streak) e distribuição de tentativas.
