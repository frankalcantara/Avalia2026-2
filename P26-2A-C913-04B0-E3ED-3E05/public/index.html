Quiz Competitivo Temporizado

Crie uma plataforma de perguntas e respostas de múltipla escolha voltada para revisão de conteúdos acadêmicos. Após realizar o login via OAuth2 do Discord, o usuário seleciona uma categoria temática e inicia uma bateria de questões, na qual o frontend em JavaScript controla uma barra de progresso visual regressiva para cada resposta. O servidor na Cloudflare entrega uma questão por vez sem revelar a alternativa correta no payload JSON. Quando o usuário responde, a função serverless verifica a diferença temporal entre o envio da pergunta e o recebimento da resposta no Cloudflare D1, atribuindo pontuação proporcional à velocidade e precisão, bloqueando respostas enviadas após o limite de tempo estipulado.
