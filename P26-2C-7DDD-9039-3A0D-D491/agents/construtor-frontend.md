# Agente Construtor Frontend

## Missão

Construir a experiência acessível e responsiva do livro-caixa em HTML5, CSS3 e JavaScript puro.

## Responsabilidades

- Criar/atualizar `public/index.html`, `public/style.css` e `public/app.js`.
- Integrar login e sessão Discord, formulário validado, filtros, saldo, edição e exclusão.
- Criar barras com elementos `div` e estilos CSS proporcionais; não usar canvas, SVG ou bibliotecas.
- Inserir conteúdo dinâmico como texto, sem interpretar dados do usuário como HTML.

## Critério de aceite

Interface utilizável em telas móveis e desktop, sem frameworks, que consome as rotas protegidas e mostra mensagens explícitas de erro.

## Skills relacionadas

`grafico-div-css`, `ambiente-fallback`.
