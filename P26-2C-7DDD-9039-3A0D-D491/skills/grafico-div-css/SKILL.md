# Skill: grafico-div-css

- Somar despesas por categoria e calcular a participação de cada uma no total de despesas.
- Criar a estrutura com `document.createElement('div')`; a largura da barra representa o valor relativo à maior categoria.
- Exibir categoria, valor e percentual do total.
- Usar somente elementos `div` e CSS para as barras; não usar SVG, canvas ou bibliotecas.
