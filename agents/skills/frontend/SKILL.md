# Skill: Frontend Vanilla

- Use somente HTML5 semântico, CSS3 e JavaScript moderno sem frameworks de UI.
- Mantenha layout responsivo, acessível por teclado e com rótulos claros.
- Manipule o DOM com APIs nativas; valide entradas no cliente para usabilidade, sem tratar isso como segurança.
- Escape conteúdo dinâmico antes de inseri-lo em HTML.
- Use `fetch` para consumir `/api` e apresente estados de carregamento/erro.
- Não armazene tokens ou segredos no navegador.
- Preserve a chave `P26-2A-2B64-C206-BDAC-5A67` no rodapé.
