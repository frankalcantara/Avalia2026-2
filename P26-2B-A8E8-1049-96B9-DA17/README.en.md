## Project specification

The Archive lets you sign in with Discord (OAuth2), save quotes with author, work, page and your own reflection, choose between public visibility (class feed) or private, search on the client by author or topic and draw a random public quote. The front end is plain HTML5, CSS3 and JavaScript (Vanilla JS), with no UI frameworks; the back end is Cloudflare Pages Functions + D1. The package also includes the agents (including the testing and validation one), `AGENTS.md`, the `skills/` folder and the MIT license.

## Features

- **Sign in with Discord (OAuth2):** session in a signed `HttpOnly` cookie, no password stored.
- **Quotes:** author, work, page and reflection; public (feed) or private visibility; instant search and a random quote.
- **Quote import:** upload `.md` or `.txt` files (or paste text), review the **editable preview** and only then save. It reads 6 formats (blockquote, "Text — Author", Kindle, front matter, labeled fields and free text). It understands labels in Portuguese and English (Quote, Author, Work, Page, Reflection, Tags and the Kindle "Your Highlight/Your Note"). Everything is imported as private and duplicates are skipped.
- **Tags and collections:** organize quotes with tags (up to 8) and your own collections, and filter by them.
- **Listen to quotes:** "Listen" and "Listen to the list" buttons. There is no voice picker: the site uses **one automatic voice** from the browser (Web Speech API) and **it follows the language of the quote text** (pt-BR or en-US); if the text is ambiguous the interface language is used, and the spoken attribution (author and work) uses the text language. It prefers Natural, Neural, Premium, Enhanced or Siri voices, then Google/Microsoft and other common ones, skips novelty voices and never uses pt-PT when pt-BR exists; if the browser has no voice in the language, it warns instead of speaking with the wrong voice. **Cloud voice (inactive):** the Google Cloud Text-to-Speech code (`POST /api/tts`, login required, server cache and usage quotas) is implemented and deployed, but **inactive**: the author decided not to create the `GOOGLE_TTS_API_KEY` key, so the site uses the browser voice. Real Google audio and the real Cloudflare cache were **never tested**. If the key is created in the future, the text being read (including private quotes) would be sent to Google Cloud, and the site would show "Natural voice generated by Google Cloud.". Still **not tested**: real speech after the latest language fix, the logged-in screens after it, a 390 px width and Safari/iOS.
- **Discord server invite (optional):** after signing in, a new user sees a single invite dialog ("Yes" or "Not now") for the server https://discord.gg/jkbgdFP7c9; the "Discord server" item stays in the menu. The link comes from the optional `DISCORD_INVITE_URL` variable.
- **PT | EN language:** button in the header; on the first visit it uses the browser language (pt* → Portuguese, en* → English, anything else → Portuguese), the choice is remembered in the browser and `?lang=` also works. The switch happens without reloading the page, stops speech, and the voice follows the language (pt-BR or en-US). The logged-in screens under the language switch and speech with real English voices are **to be validated by the author**. Quote texts are user content and are not translated.
- **Accessibility and theme:** keyboard navigation, large touch targets on mobile and a light/dark theme.

## How to publish this subfolder on Cloudflare Pages + D1 + Discord OAuth2

1. In the Cloudflare dashboard (**Workers & Pages** → **Create** → **Pages** → **Connect to Git**), select your fork of the `Avalia2026-2` repository.
2. Configure the build settings pointing to this subfolder:
   - **Root directory:** `P26-2B-A8E8-1049-96B9-DA17`
   - **Build command:** *(leave empty — plain HTML/CSS/JS)*
   - **Build output directory:** `public`
3. Create the D1 database and apply the migrations (in the lab terminal using Scoop):
   ```powershell
   cd P26-2B-A8E8-1049-96B9-DA17
   npx.cmd wrangler d1 create db-p26-2b-a8e8-1049-96b9-da17
   # Copy the generated database_id into wrangler.jsonc and run:
   npx.cmd wrangler d1 migrations apply DB --remote   # applies migrations 0001 to 0005 (0005 creates the `tts_usage` table for voice quotas)
   ```
4. **Bind the D1 database to your Cloudflare Pages project (required to enable env.DB):**
   - In the Cloudflare dashboard: open your Pages project → **Settings** → **Functions** → **D1 database bindings**.
   - Click **Add binding**:
     - **Variable name:** `DB`
     - **D1 database:** select the database you created (`db-p26-2b-a8e8-1049-96b9-da17`).
5. **Discord OAuth2 setup (required for real authentication):**
   - Open the **Discord Developer Portal** (https://discord.com/developers/applications) and create a new Application.
   - In the **OAuth2** tab:
     - Copy the **Client ID** and generate the **Client Secret**.
     - Under **Redirects**, add the exact deployment URL:
       `https://p26-2b-a8e8-1049-96b9-da17.pages.dev/api/auth/discord/callback`
   - In your project on Cloudflare Pages:
     - Open **Settings** → **Environment variables**.
     - Add the environment variables:
       - `DISCORD_CLIENT_ID`
       - `DISCORD_CLIENT_SECRET`
       - `SESSION_SECRET`
     - Optional (not a secret): `DISCORD_INVITE_URL`, with the invite link (`https://discord.gg/jkbgdFP7c9`). Without it, the invite dialog does not appear.
     - Optional, **natural cloud voice** (`GOOGLE_TTS_API_KEY`, stored as a *secret*; without it the feature stays inactive and the browser voice is used): in Google Cloud, enable the **Cloud Text-to-Speech API**, create an API key **restricted to that API** and set up a **budget with a billing alert**. After storing the secret, redeploy the site. Optional tuning variables: `TTS_DAILY_USER_CHARS` (default 30,000 characters/day per user), `TTS_MONTHLY_CHARS` (default 700,000/month overall, below the free tier), `TTS_VOICE_PT` (default `pt-BR-Neural2-A`) and `TTS_VOICE_EN` (default `en-US-Neural2-F`). Each request accepts up to 1500 characters.
6. Update the **URL_CLOUDFLARE** field at the top of the `README.md` with the public address generated by Cloudflare.
7. At the repository root, run `node validar-local.mjs P26-2B-A8E8-1049-96B9-DA17` to validate every criterion before committing.

**Tests:** `node --test tests/*.test.mjs` (42 tests). **Local development:** `npx wrangler pages dev public --port 8788`.
