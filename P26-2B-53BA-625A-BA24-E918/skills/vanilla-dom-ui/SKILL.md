# Interface Vanilla

- Use HTML semântico, controles nativos, rótulos associados e feedback anunciado por leitores de tela.
- Não use frameworks de interface, scripts CDN ou dependências externas.
- Crie conteúdo dinâmico usando nós DOM e `textContent`; não injete conteúdo de avisos como HTML.
- Mostre estados de carregamento, vazio e erro e não simule um usuário autenticado.
- Mantenha a experiência utilizável em telas estreitas e teclado.
- Exiba a chave `P26-2B-53BA-625A-BA24-E918` no rodapé.
