Campo Minado com Tabela de Recordes

Construa uma implementação web do Campo Minado com geração de tabuleiros personalizáveis. O JavaScript no cliente deve capturar eventos de clique esquerdo (revelar célula) e clique direito (marcar bandeira), utilizando recursão no DOM para abrir áreas vazias adjacentes quando o servidor informar ausência de minas no perímetro. Para impedir que o estudante inspecione a localização das minas pelo console do navegador, a matriz real do jogo deve ser gerada e retida no Cloudflare D1 ou KV, associada à sessão OAuth2 do Discord do jogador. Cada jogada consulta a API na Cloudflare, que retorna o valor numérico da vizinhança ou encerra a partida em caso de explosão, computando o tempo final nos recordes globais em caso de vitória.
