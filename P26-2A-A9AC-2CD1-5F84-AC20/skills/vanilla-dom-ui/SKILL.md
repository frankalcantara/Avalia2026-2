# Skill: Interface Web em HTML5, CSS3 e Vanilla JS

## Regras obrigatórias
1. **Sem frameworks de UI:** nada de React, Vue, Angular ou Svelte; atualização de estado com a API nativa do DOM.
2. **Texto de usuário com `textContent`:** nunca `innerHTML` com dados digitados (evita XSS).
3. **Gráfico só com `<div>`:** barras horizontais com largura em porcentagem do gasto por categoria (`style.width`).
4. **Validação monetária no cliente** (`25,90`, `25.90`, `1.234,56`), repetida no servidor.
5. **Tipografia limpa:** sem `text-shadow` ou `drop-shadow` em texto; contraste suficiente.
6. **Acessibilidade e responsividade:** foco visível, `prefers-reduced-motion` respeitado, layout que funciona em celular, tabela com rolagem própria.
7. **Rastreabilidade:** chave única `P26-2A-A9AC-2CD1-5F84-AC20` no `<footer>`.
