Cápsula do Tempo e Livro de Visitas Digital

Desenvolva um sistema de mensagens históricas e livro de assinaturas para turmas de graduação. O usuário faz login via Discord OAuth2 para deixar depoimentos no mural público imediato ou para criar "cápsulas do tempo" — mensagens endereçadas à turma ou a si mesmo com uma data futura de desbloqueio (ex: data da formatura). A segurança temporal deve ser garantida pelas Cloudflare Pages Functions: ao consultar a lista de cápsulas no Cloudflare D1, o servidor compara a data atual com a coluna unlock_date. Se a data futura ainda não chegou, o backend retorna apenas os metadados (autor, título e contagem regressiva), omitindo completamente o texto da mensagem no JSON enviado ao navegador.
