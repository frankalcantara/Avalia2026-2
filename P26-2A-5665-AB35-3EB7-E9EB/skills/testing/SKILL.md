# Skill: teste e validação de entrega

Compare a implementação com cada requisito obrigatório, sem inferir os requisitos de produto que estejam ocultos ou ausentes. Confira a URL implantada e os endpoints principais; para operações de gravação em produção use somente registros temporários identificáveis e remova-os após a validação. Separe fatos conferidos, lacunas e dependências externas. Não edite arquivos nem dados quando a tarefa for somente de revisão.
