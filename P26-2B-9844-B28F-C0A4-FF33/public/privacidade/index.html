Política de Privacidade

Login e dados recebidos

O login é feito pelo Discord usando OAuth2 com o escopo identify. Nesse fluxo, o fórum recebe o identificador da conta Discord, o nome de usuário, o nome de exibição quando disponível e a informação do avatar. O escopo de e-mail não é solicitado, e o fórum não recebe sua senha do Discord.

Finalidade do uso

Esses dados são usados para identificar a conta no fórum, exibir o nome e o avatar junto às publicações e verificar, no servidor, quem criou uma pergunta para permitir que essa pessoa marque uma resposta como solução.

Armazenamento

O identificador Discord, nome e avatar são registrados no banco Cloudflare D1. O mesmo banco armazena perguntas, respostas, autoria e estado de resolução, além das datas registradas pelo sistema. O token OAuth é usado durante o login para consultar o perfil, mas não é gravado pelo código do fórum.

Após o login, uma sessão assinada é mantida em cookie HttpOnly com validade de 24 horas; em conexões HTTPS, o cookie também usa Secure. O código não define um prazo automático de retenção para perguntas, respostas ou registros de usuário.

Solicitação de exclusão

O fórum não oferece um botão de exclusão automática. Para solicitar a exclusão de dados, entre em contato com o responsável pelo projeto pelo canal da disciplina no AVA. Informe seu nome de usuário Discord e, se possível, o identificador da conta, além das publicações que deseja localizar. O responsável precisará tratar o pedido no banco; a aplicação não executa essa exclusão automaticamente.

Projeto acadêmico

Este é um projeto acadêmico independente e não possui vínculo oficial com o Discord.
